# Security

## Supported versions

Only the latest published release receives security patches. Older versions
should be upgraded.

## Reporting a vulnerability

Do **not** open a public GitHub issue for a security vulnerability.

Instead, report it privately through the
[GitHub Security Advisories](https://github.com/timotheegath/infomaniak-http-calendar-mcp/security/advisories/new)
page. The report will be acknowledged and triaged as soon as practical, with
follow-up about remediation and release planning where applicable.
